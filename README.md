# TaskManager API

TaskManager API es un sistema desarrollado para gestionar tareas mediante una API REST. Permite crear, consultar, actualizar y eliminar tareas, facilitando la organización y administración de actividades.

## Funcionamiento

El sistema permite registrar tareas con un título, descripción, estado y prioridad. También ofrece la posibilidad de consultar las tareas registradas, modificar su información y eliminarlas cuando ya no sean necesarias.

Además, permite adjuntar archivos a las tareas, consultar los documentos asociados y eliminarlos cuando sea necesario.

El sistema incorpora comunicación en tiempo real para notificar automáticamente a los clientes conectados cuando una tarea es creada, actualizada o eliminada.

## Características principales

- Gestión completa de tareas.
- Almacenamiento persistente de información.
- Adjuntar y administrar archivos.
- Validación de datos y formatos de archivos.
- Notificaciones en tiempo real sobre los cambios de las tareas.

## Ejecución

El proyecto requiere Node.js y una base de datos MySQL configurada. Una vez instaladas las dependencias y preparada la base de datos, se puede iniciar el servidor para utilizar la API localmente.
